# Портфолио - Nursultan Bergaliev

Статический сайт-портфолио: главная плюс 5 отдельных страниц кейсов, тёмная тема, переключение EN/RU.

## Структура

```
index.html                 главная: hero, кейсы, опыт, навыки, контакты
work/invitro.html          кейс: медицинская регистратура (Invitro)
work/avito.html            кейс: планировщик интервью (Avito)
work/wink.html             кейс: CMS стримингового сервиса (Wink / Ростелеком)
work/siemens.html          кейс: CMS планирования мощностей (Siemens)
work/umi.html              кейс: сайты и магазины на UMI.CMS
assets/style.css           вся стилизация
assets/site.js             переключатель языка (~40 строк)
Nursultan_Bergaliev_CV.pdf резюме, скачивается кнопкой с главной
.nojekyll                  чтобы GitHub Pages не прогонял файлы через Jekyll
src/                       генератор страниц (нужен только для правок контента)
```
